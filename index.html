Questions

Everything you need to know

Does PeakSense upload my videos anywhere?

No. Every step — download, transcription, detection, rendering, and subtitling — runs locally on your machine. The only network calls are to the platforms you're actively downloading from or posting to, and to HuggingFace if you enable speaker diarization.

What GPU do I need?

PeakSense falls back to CPU rendering and CPU transcription automatically, so it runs on anything. If you have an NVIDIA GPU, it'll use CUDA for Whisper and NVENC for rendering, which is dramatically faster. AMD and Intel GPUs work through their respective encoders (QSV/AMF).

Do I need an API key for the AI detection?

No. PeakSense uses Ollama for local LLM scoring — you run the model yourself. There's no OpenAI key, no Anthropic key, no per-token billing. If you'd rather not use AI scoring at all, the loudness, hype-phrase, chat, and trigger-phrase detectors work independently.

How is this different from Opus Clip or Eklipse?

Three things: (1) it runs locally, so your footage never leaves your PC; (2) it has no clip credits — you can process as many VODs as your hardware can handle; and (3) it includes facecam-top layouts, speaker diarization, and a full montage builder that most cloud tools either gate behind paid tiers or don't offer at all.

Can I schedule posts to multiple platforms?

Yes. PeakSense has a posting scheduler where you set days and times. Clips are assigned to the next available slot in ranking order and posted automatically. YouTube and TikTok are supported today, with Twitch clip creation built in for live streams.

Is there a free tier?

PeakSense is self-hosted — there's no metered tier at all. You install it, point it at your hardware, and use it as much as you want.
