PEAKSENSE

PeakSense is a personal desktop application used by a content creator to process their own stream recordings. It downloads video the user already owns from platforms they connect (such as YouTube and Twitch), analyzes it entirely on the user's own computer using speech transcription and audio analysis, and produces short highlight clips. The user can then choose to publish those clips to their own connected social media accounts.

All processing happens locally on the user's own device. PeakSense does not operate any central server that stores or transmits user video content.
